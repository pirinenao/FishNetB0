FishNetB0 demo

FishNetB0 is a lightweight, EfficientNetB0-based image classification model designed to identify common Finnish fish species.
Available species: Ahven, Harjus, Hauki, Kiiski, Kirjolohi, Kuha, Lahna, Lohi, Made, Pasuri, Särki, Säyne, Siika, Taimen
Model runs directly in your browser, and no data is sent to the server.
